 # Day 26 – Expense Tracker using Python 💰

## 📌 Project Overview

This project is a simple Expense Tracker built using Python.

It allows users to add, manage, and delete income and expense records through a graphical interface while storing all data in a local SQLite database.

---

## 🚀 Features

* Add Income and Expense
* Delete Transactions
* Automatic Balance Calculation
* SQLite Database Storage
* Simple GUI Interface

---

## 🛠 Technologies Used

* Python 3
* Tkinter
* SQLite3
* Datetime Module

---

## ▶ How to Run

```bash
python expense_tracker.py
```
