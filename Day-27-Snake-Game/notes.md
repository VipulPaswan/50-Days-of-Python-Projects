# Day 27 – Snake Game using Python 🐍

## 📌 Project Overview

This project is a classic Snake Game developed using Python and the Pygame library.

The player controls the snake, collects food to increase the score, and avoids collisions with the walls and its own body.

---

## 🚀 Features

* Start Screen
* Snake Movement
* Random Food Generation
* Score Tracking
* Game Over Screen
* Play Again Option
* Quit Option

---

## 🛠 Technologies Used

* Python 3
* Pygame

---

## 📦 Installation

Install the required library:

```bash
pip install pygame
```

---

## ▶ How to Run

```bash
python snake_game.py
```

---

## 🎮 Controls

* SPACE → Start Game
* ↑ → Move Up
* ↓ → Move Down
* ← → Move Left
* → → Move Right
* C → Play Again
* Q → Quit
