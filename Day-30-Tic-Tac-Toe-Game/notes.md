# Day 30 – Tic Tac Toe Game using Python ❌⭕

## 📌 Project Overview

This project is a GUI-based Tic Tac Toe game built using Python and Tkinter.

Two players take turns placing X and O on a 3×3 board. The game automatically checks for a winner or a draw after every move.

---

## 🚀 Features

* Modern GUI Interface
* Two Player Gameplay
* Turn Indicator
* Winner Detection
* Draw Detection
* Restart Game Button

---

## 🛠 Technologies Used

* Python 3
* Tkinter

---

## ▶ How to Run

```bash
python tic_tac_toe.py
```
