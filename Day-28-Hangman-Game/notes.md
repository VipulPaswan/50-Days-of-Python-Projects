# Day 28 – Hangman Game using Python 🎮🐍

## 📌 Project Overview

This project is a GUI-based Hangman Game developed using Python and Tkinter.

The player has to guess the hidden word one letter at a time. Every wrong guess draws a new part of the hangman. The game ends when the player successfully guesses the word or runs out of lives.

---

## 🚀 Features

* Modern GUI Interface
* Random Word Selection
* Interactive Alphabet Buttons
* Hangman Drawing
* Lives Counter
* Win and Lose Messages
* New Game Button

---

## 🛠 Technologies Used

* Python 3
* Tkinter
* Random Module

---
