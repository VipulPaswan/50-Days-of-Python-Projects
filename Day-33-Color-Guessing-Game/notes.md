Day 33 – Color Guessing Game using Python 🎨
📌 Project Overview

This project is a simple and interactive Color Guessing Game built using Python and Tkinter.

The objective is to type the color of the displayed text, not the word itself. The player earns points for every correct answer within the 30-second time limit.

🚀 Features
Interactive GUI
Random Color Generation
Live Score Counter
30-Second Timer
Keyboard-Based Gameplay
Beginner-Friendly Project
🛠 Technologies Used
Python 3
Tkinter
Random Module
▶ How to Run
