# Day 31 – Dice Rolling Simulator using Python 🎲

## 📌 Project Overview

This project is a simple Dice Rolling Simulator built using Python and Tkinter.

The application generates a random number between 1 and 6 whenever the user clicks the "Roll Dice" button, simulating a real dice roll.

---

## 🚀 Features

* GUI-Based Application
* Random Dice Generation
* Interactive User Interface
* Beginner-Friendly Project

---

## 🛠 Technologies Used

* Tkinter
* Random Module
