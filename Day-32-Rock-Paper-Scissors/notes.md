# Day 32 – Rock Paper Scissors using Python ✊📄✂️

## 📌 Project Overview

This project is a simple Rock Paper Scissors game built using Python.

The player selects Rock, Paper, or Scissors, and the computer randomly chooses one option. The game then determines the winner based on the standard rules.

---

## 🚀 Features

* User vs Computer Gameplay
* Random Computer Choice
* Winner Detection
* Interactive GUI
* Beginner-Friendly Project

---

## 🛠 Technologies Used

* Python 3
* Tkinter
* Random Module

---

## ▶ How to Run

```bash
python rock_paper_scissors.py
```
